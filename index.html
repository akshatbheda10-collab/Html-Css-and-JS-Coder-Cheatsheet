Python

Python is a language for giving the computer clear instructions. Spaces at the start of a line matter in Python!

Show a message

print() puts words or a result on the screen.

print("Hello, world!")

Save information in a variable

A variable is a labeled box that holds a value.

name = "Maya"
print(f"Hi, {name}!")

Make a choice with if

The computer checks a question. It runs the matching part.

score = 8
if score >= 5:
    print("You passed!")
else:
    print("Try again!")

Repeat with a loop

A for loop repeats its indented lines for each item.

pets = ["cat", "dog", "fish"]
for pet in pets:
    print(pet)

Make a reusable function

A function is a set of instructions you can use by its name.

def say_hello(name):
    print(f"Hello, {name}!")

say_hello("Sam")

Ask the user a question

input() waits for someone to type. It gives back text.

favorite = input("Favorite color? ")
print(f"I like {favorite}, too!")

from django.contrib.auth.forms import \
        UserCreationForm

def register(request):
    """Register a new user."""

    if request.method != 'POST':
        # Display blank registration form.
        form = UserCreationForm()

    else:
        # Process completed form.
        form = UserCreationForm(
                data=request.POST)

        if form.is_valid():
            new_user = form.save()

            # Log in, redirect to home page.
            login(request, new_user)
            return redirect(
                    'learning_logs:index')

    # Display a blank or invalid form.
    context = {'form': form}

    return render(request,
        'registration/register.html', context)

  Visit this page

<ul>
  <li>Apples</li>
  <li>Oranges</li>

<header>Top of the page</header>

<footer>Bottom of the page</footer>

Buttons are for actions. Use a paragraph for a new paragraph; use <br> only for a line break inside text.

<button type="button">Press me</button>

Make an ordered list

Use <ol> when the order matters, such as steps in a recipe.

<ol>
  <li>Wash your hands</li>
  <li>Mix the ingredients</li>
  <li>Bake the muffins</li>
</ol>

  <tr><td>Owls</td><td>12</td></tr>

Create a simple form

A label tells people what to enter. Matching for and id connect them.

<form>
  <label for="nickname">Your nickname</label>
  <input id="nickname" name="nickname" type="text">
  <button type="submit">Send</button>
</form>

Choose the right input

Input types help a browser show the right keyboard and check the value.

<input type="email" name="email" required>
<input type="number" name="age" min="1" max="120">
<input type="date" name="birthday">

Add a longer answer box

Use textarea for a message that may take more than one line.

<label for="message">Your message</label>
<textarea id="message" name="message" rows="4"></textarea>

Add sound or video

Controls let visitors play, pause, or change the volume. Include fallback text.

<audio controls src="song.mp3">Audio is not supported.</audio>
<video controls width="480" src="movie.mp4">Video is not supported.</video>

<!-- Remember to add a page title -->

CSS

CSS controls how a web page looks: colors, text, spacing, and where things sit.

Pick a color and font

A selector names what you want to style. This one styles every paragraph.

p {
  color: navy;
  font-family: Arial, sans-serif;
}

Style a heading

Each style is a property followed by a value.

h1 {
  color: purple;
  text-align: center;
}

Use a class for one part

A class lets you style selected elements. In CSS, its name starts with a dot.

.important {
  background-color: #fff0b3;
  padding: 12px;
}

Add a border and space

padding is space inside the border. margin is space outside it.

.card {
  border: 2px solid steelblue;
  padding: 16px;
  margin: 12px;
}

Line things up

Flexbox makes it easier to place items next to each other.

.row {
  display: flex;
  gap: 12px;
  align-items: center;
}

Choose what to style

A tag selector styles every matching tag. A class starts with a dot; an id starts with #.

p { color: #253858; }
.note { background: lightyellow; }
#main-title { font-size: 2rem; }

Style links and hover

A pseudo-class styles an element in a particular state, such as when a pointer is over it.

a { color: #3157d5; }
a:hover { color: #19368e; }
button:focus-visible { outline: 3px solid orange; }

Understand the box model

Every box has content, padding, border, and margin. This rule makes sizing easier to predict.

* { box-sizing: border-box; }
.card {
  width: 240px;
  padding: 16px;
  border: 2px solid navy;
  margin: 12px;
}

Set a background

Backgrounds can use colors or images. Keep text readable over them.

body {
  background-color: #f4f7ff;
  background-image: linear-gradient(white, #eaf0ff);
}

Style text and spacing

Line height and letter spacing can make text easier to read.

p {
  font-size: 1rem;
  line-height: 1.6;
  letter-spacing: 0.02em;
  text-align: left;
}

Make a layout with grid

Grid is useful for arranging items in rows and columns.

.cards {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 16px;
}

Line items up with flexbox

Flexbox arranges items in a row or column and can add space between them.

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 12px;
}

Change layout for small screens

A media query applies styles only when the screen is narrow.

@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
  body { padding: 12px; }
}

Use a CSS variable

Variables store reusable values. They start with two dashes and are read with var().

:root { --favorite-color: #3157d5; }
button {
  color: white;
  background: var(--favorite-color);
}

Add a small animation

Transitions make a style change feel smooth. Respect the reduced-motion setting.

button { transition: transform 0.2s ease; }
button:hover { transform: scale(1.04); }
@media (prefers-reduced-motion: reduce) {
  button { transition: none; }
}

Control size and overflow

max-width keeps an image from spilling out of its box.

img {
  max-width: 100%;
  height: auto;
}
.long-list { overflow-x: auto; }

JavaScript

JavaScript makes a page interactive. It can remember information, make choices, and react to clicks.

Remember a value

Use const for a value you will not replace and let for one that can change.

const player = "Ari";
let points = 0;
points = points + 1;

Make a choice

JavaScript runs one block when a test is true and another when it is false.

if (points > 0) {
  console.log("Nice job!");
} else {
  console.log("Start playing!");
}

Repeat an action

This loop counts from 1 up to 3. It stops before 4.

for (let n = 1; n <= 3; n++) {
  console.log(n);
}

Write a function

A function stores steps you can run again by calling its name.

function sayHi(name) {
  return "Hi, " + name + "!";
}

console.log(sayHi("Lee"));

React to a button click

This finds a button on the page and listens for a click.

const button = document.querySelector("button");
button.addEventListener("click", () => {
  alert("You clicked it!");
});

Put JavaScript in a web page

An external file is easier to organize. The defer option waits until the page is read.

<script src="app.js" defer></script>

Use comments and basic values

Comments explain code to people. JavaScript has numbers, text, true/false values, and more.

// Keep track of the game
const player = "Nia";
let score = 0;
const isPlaying = true;

Work with arrays and objects

An array is an ordered list. An object groups details under names.

const colors = ["red", "blue", "green"];
colors.push("yellow");
console.log(colors[0]);

const pet = { name: "Pip", kind: "cat" };
console.log(pet.name);

Use math and comparisons

Math operators do arithmetic. === checks both value and type, so it is usually safer than ==.

const total = 8 + 3 * 2;
const remainder = 10 % 3;
const isSame = (5 === 5);
const canPlay = (score > 0 && isPlaying);

Change or search text

String methods can change letter case, split text, or find part of a word.

const shout = "hello".toUpperCase();
const words = "red blue".split(" ");
const hasBlue = words.includes("blue");
const newName = "Sam".replace("Sam", "Sami");

Make a function that returns an answer

Parameters are the inputs. return sends an answer back to the place that called the function.

function add(a, b) {
  return a + b;
}
const answer = add(4, 6);

Repeat with while and break

A while loop repeats while its test is true. Change something inside it so it can end.

let count = 1;
while (count <= 3) {
  console.log(count);
  count++;
}

Use Math and random numbers

Math.random() gives a number from 0 up to (but not including) 1.

const diceRoll = Math.floor(Math.random() * 6) + 1;
const bigger = Math.max(4, 9, 2);
const rounded = Math.round(3.6);

Work with dates

Date can tell you the current time or the parts of a date. Months start at 0 when using getMonth().

const now = new Date();
const year = now.getFullYear();
const month = now.getMonth() + 1;
const day = now.getDate();

Find and change a page element

The DOM is the browser’s map of the page. querySelector finds the first matching element.

const title = document.querySelector("h1");
title.textContent = "Welcome!";
title.classList.add("highlight");

Listen for a click

An event listener runs a function when an event happens.

const button = document.querySelector("button");
button.addEventListener("click", () => {
  console.log("Clicked!");
});

Read a form safely

The submit event happens when a form is sent. preventDefault stops the browser from reloading the page.

const form = document.querySelector("form");
form.addEventListener("submit", event => {
  event.preventDefault();
  const answer = form.elements.nickname.value;
  console.log(answer);
});

Remember a small setting

localStorage keeps simple text on this device between visits. Do not put passwords or secrets here.

localStorage.setItem("theme", "dark");
const theme = localStorage.getItem("theme");
localStorage.removeItem("theme");

Handle a problem

try and catch let a program respond when something goes wrong.

try {
  const data = JSON.parse("{bad json}");
} catch (error) {
  console.log("That data could not be read.");
}

Check text with a pattern

A regular expression can check a simple pattern. This one checks for digits.

const hasDigits = /\d+/.test("Room 12");
const cleaned = "  hello  ".trim();

Use a timer

setTimeout runs a function once after a delay in milliseconds.

setTimeout(() => {
  console.log("One second passed!");
}, 1000);

Understand the browser window

The window is the browser tab. Use alerts sparingly; page content is usually friendlier.

console.log(window.innerWidth);
console.log(window.location.href);
// Avoid putting private information in a URL.

Use keyboard and pointer events

The same page can react to different kinds of user actions.

document.addEventListener("keydown", event => {
  if (event.key === "Escape") console.log("Escape pressed");
});

button.addEventListener("mouseover", () => {
  console.log("Pointer is over the button");
});
